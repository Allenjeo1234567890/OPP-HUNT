# Opp Hunt 🚀

Opp Hunt is a free platform for students and professionals to discover opportunities from around the world.

## Features

* Internships
* Hackathons
* Scholarships
* Competitions
* Jobs
* Fellowships
* Free Courses
* Modern Responsive UI
* Dark Mode Support
* Search and Filters
* No Login Required
* Completely Free

## Tech Stack

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript

## Installation

```bash
pip install -r requirements.txt
python app.py
```

## Deployment

This project can be deployed on Vercel.
